# Grid Pop!

免費休閒益智遊戲。把方塊拖到 8×8 棋盤，填滿一列或一行就會消除。

聯絡：ycmcnsbus@gmail.com

## 給不懂程式的人（上傳 GitHub / Vercel）

1. 解壓這個資料夾，**不要**刪除裡面的 `package.json`、`src`、`public`。
2. 用 GitHub Desktop 把**整個資料夾**發佈到 GitHub（見對話裡的逐步教學）。
3. 到 [vercel.com/new](https://vercel.com/new) 用 GitHub 匯入這個倉庫，直接按 **Deploy**。
4. 不要上傳 `node_modules`（解壓後也不會有這個資料夾；Vercel 會自己安裝）。

遊戲在網站上即可遊玩。私隱政策、使用條款、聯絡我們在主選單底部與設定頁。
